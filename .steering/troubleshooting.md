# トラブルシューティング / 過去に踏んだ罠

実際のセッションで踏んだ罠と対処。同じ調査を繰り返さないための記録。

## 生成スクリプトの出力を head で切らない

`npm run gallery` / `npm run docs-shot` など長時間の生成コマンドの出力を `| head` に通すと、
head がパイプを早期に閉じた時点で **SIGPIPE によりスクリプトが途中終了**する。
「テーマが1つだけ欠ける」「PNGの枚数が合わない」という壊れ方に見えるので原因に気づきにくい。
出力を確認したいときはファイルにリダイレクトしてから読む:

```bash
npm run gallery -- --no-open > /tmp/gallery.log 2>&1; echo "exit=$?"
```

## docs/*.png の差分は再実行してから判断する

Chrome のレンダリングにはごく稀に揺らぎがあり、内容が同じでも1回だけピクセル差が出ることがある。
`git diff` で docs/*.png に差分が出たら、**同じプリセットをもう一度生成して**ハッシュが安定するか確認する。
再実行で committed 版と一致するなら回帰ではない。

## theme-check の淡色表紙判定は「文字色」で行う

淡色表紙のテーマ（pastel 系）でも `--primary` は**文字用の濃色**であることがあるため、
「表紙が淡色かどうか」を `--primary` の輝度では判定できない。
淡色表紙のテーマは `--on-primary-*` に濃色文字を入れる、という関係が本質なので、
**表紙に乗る文字色（`--on-primary-sub`）の輝度**で判定している（`scripts/theme-check.mjs`）。

## その他の小さな罠

- **zsh は `=` で始まる引数を展開する**（`echo ===` が `== not found` になる）。区切り線などはクォートする
- **`.gallery/` は生成後も消さない仕様**。index.html が中のPNGを相対参照するため（.gitignore 済み）。`.docs-shot/` は毎回削除される
- ギャラリー・docs-shot の見本デッキで**強調（`**`）でコードチップ（`` ` ``）を挟むと、チップ外の文字だけ色付く**（marp-deck スキルの style-rules.md 参照。実際に踏んだバグが規約化されたもの）
- `themes/*.css` を編集すると PostToolUse hook（`.claude/hooks/theme-changed.sh`）が検査と登録先の案内を注入する。hook は `jq` が無い環境ではスキップした旨を出す
