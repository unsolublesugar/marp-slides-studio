# スライドのスタイルルール

## 配色

- 色はテーマのCSS変数のみを使う。新しい色コードをスライド内に直書きしない
- アクセント色（`var(--accent)`）の使用は1スライドあたり1〜2箇所まで
- 強調は `<strong>`（primary色・太字）を基本とし、1項目につき1箇所まで
- 強調でコード（`` ` ``）を挟まない。コードは自前の色を持つため、`` **`/` と `/app`** `` のように書くと
  チップの外の「と」だけが色付く。コードは既にチップの背景で目立つので、強調は地の文側に付ける

## テキスト量

- 箇条書きは1スライド5項目まで。あふれたらスライドを分割する
- 1項目は1行（〜35文字）を基本、折り返しは2行まで
- 見出しは体言止めまたは短文。「〜について」は使わない
- スライド1枚につき伝えたいことは1つ

## レイアウト

- patterns.md にあるパターンだけで組む。新パターンが必要ならテーマCSSに追加してからカタログ（template/slides.md と patterns.md）にも登録する
- インラインstyleは幅調整（`max-width` など）に限定し、色・フォント指定には使わない
- 画像には必ず `alt` を付ける。キャプションは `.shot-cap` で1行

## 構成

- 表紙(title) → アジェンダ → 章扉(section)+本文(content) → まとめ(learn-grid) → 参考(reference) → 締め(closing) を標準構成とする
- 章扉のCHAPTER番号は 01, 02, ... のゼロ埋め2桁
- 発表時間の目安: 1スライド30秒〜1分。LT(5分)なら10枚前後
